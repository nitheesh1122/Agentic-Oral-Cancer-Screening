# Project Overview

The objective of this research is to develop an explainable and trustworthy AI-based oral cancer screening framework using an Agentic Vision-Language architecture. Unlike conventional deep learning models that provide only classification outputs, the proposed framework integrates lesion detection, segmentation, multimodal reasoning, medical knowledge retrieval, evidence verification, confidence estimation, and clinician-oriented recommendations.

The project is currently in the Research and Initial Development phase.

# Work Completed

## 1. Problem Definition

The problem statement was finalized after reviewing existing oral cancer diagnosis systems. Major shortcomings identified include:

- Lack of explainability
- Black-box predictions
- No evidence verification
- Limited clinical reasoning
- Absence of confidence estimation

---

## 2. Literature Review

A comprehensive literature survey covering approximately twenty research papers has been completed.

The review includes:

- Oral cancer detection
- Deep Learning
- Vision Transformers
- Vision-Language Models
- Explainable AI
- Medical Retrieval-Augmented Generation
- Multi-Agent Systems
- Clinical Decision Support

The findings were used to identify research gaps and formulate the proposed framework.

---

## 3. Research Gap Identification

Based on the literature review, the following research gaps were identified:

- Existing systems focus mainly on classification.
- Very few systems integrate Vision-Language Models.
- Explainability is limited.
- Evidence verification is absent.
- Confidence estimation is rarely considered.
- No comprehensive agentic framework exists for oral cancer screening.

---

## 4. Proposed Framework

The proposed framework consists of eleven specialized AI agents that collaboratively perform oral cancer screening.

The designed workflow includes:

1. Image Quality Assessment
2. Lesion Detection
3. Lesion Segmentation
4. Vision-Language Understanding
5. Clinical Feature Extraction
6. Medical Knowledge Retrieval
7. Clinical Reasoning
8. Evidence Verification
9. Confidence Estimation
10. Recommendation Generation
11. Interactive Dashboard

---

## 5. Technology Selection

The major technologies selected for implementation include:

| Module | Selected Technology |
|---------|--------------------|
| Image Quality Assessment | BRISQUE + OpenCV |
| Lesion Detection | YOLOv11 |
| Lesion Segmentation | SAM 2 |
| Vision-Language Understanding | MedGemma |
| Medical Knowledge Retrieval | FAISS + LangChain |
| Agent Orchestration | LangGraph |
| Confidence Calibration | Platt Scaling |
| Dashboard | Streamlit + FastAPI |
